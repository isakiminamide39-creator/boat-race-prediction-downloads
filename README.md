# BOAT RACE データ予測アプリ 配布ページ

このリポジトリは、BOAT RACE データ予測アプリのインストールファイルを配布するためのページです。

## 対応環境

- Windows版：Windows 10／Windows 11（64ビット）
- Android版：Android 8.0以降
- iPhone版：iOS 16以降（Safariで利用）

Windows 7／8／8.1、32ビット版Windowsはサポート対象外です。

## Windows版

インストールファイルは[最新版のダウンロードページ](https://github.com/isakiminamide39-creator/boat-race-prediction-downloads/releases/tag/v1.3.1)から取得できます。

- 製品バージョン：1.3.1
- ファイル名：`BoatRacePrediction_Windows_1.3.1_Setup.exe`
- SHA-256：`AA975204A0571F5C2CC0E7914DE28574064CE90C4E3512D1762AA82DA41D46DB`

直近1年50,955レースを使用し、最後の未使用8,318レースで確率を点検したモデルを搭載しています。締切前に保存した予測と確定結果を照合し、レース一覧と各買い目に「あたり」を表示します。

## Android版

- 製品バージョン：1.3.0
- 対応：Android 8.0以降
- ファイル名：`BoatRacePrediction_Android_1.3.0.apk`
- SHA-256：`83F545BDA5234E900A0104CA098CF25C4CEC40258B7969C10AEF9BDD673975F9`

Android版は専用リリース鍵で署名しています。

## iPhone・スマホ版

- iPhone：iOS 16以降のSafari
- Android：Android 8.0以降のChrome
- ホーム画面へ追加すると、通常のアプリに近い操作で起動できます
- 展示タイム、展示スタート、展示進入、オッズ、終了レースのあたり判定に対応
- 直近1年54,619レースの展示順位とまくり差し実績を、展開の発生目安へ反映

購入者専用URLは公開リポジトリには掲載していません。購入時に案内されたnote記事から起動してください。

現在のWindows版インストーラーには認証局のコード署名がないため、Windowsの警告画面が表示される場合があります。配布ファイルはMicrosoft Defenderで脅威が検出されないことを確認しています。必要に応じて上記SHA-256と一致することも確認してください。
