# BOAT RACE データ予測アプリ 配布案内

ボートレース予測を整理して確認するための非公式アプリです。的中や利益を保証するものではありません。舟券の購入は20歳以上の方が、無理のない金額で行ってください。

## 毎月更新されます

- アプリは月ごとに利用期限を設定しています。
- 2026年8月版の利用期限は、2026年8月31日23時59分（日本時間）です。
- 翌月は新しいインストールファイルと専用リンクへ更新します。
- 継続中の方は、noteの「ボートレース予測アプリ」プランの記事から最新版を取得してください。
- noteに掲載するダウンロード先は毎月変更します。古いファイルや古いリンクは利用できなくなります。

## 対応端末

- Windows：Windows 10／11（64ビット）
- Android：Android 8.0以降
- iPhone：iOS 16以降のSafari

## 2026年8月版

- Windows：`BoatRacePrediction_Windows_1.4.0_Setup.exe`
- Android：`BoatRacePrediction_Android_1.4.0.apk`
- iPhone：noteの購入者向け記事に掲載する2026年8月専用リンクから利用

## 通信と安全確認

- データ取得にはインターネット接続が必要です。通信料は利用者負担です。
- Windows版とAndroid版は、公開前にファイルのSHA-256を確認して掲載します。
- BOAT RACE公式サイトとは無関係の非公式アプリです。欠場・中止・直前変更・最終オッズは必ず公式サイトで確認してください。
